# Lab 1 — Requirements Engineering & UML Use-Case Modelling

**Problem Statement #36 — Restaurant Table Booking & Pre-Ordering App**
Software Engineering Lab, Dept. of CSE, PES University

Name: `Adyanth Mallur` · SRN: `PES1UG24CS036`

## Scenario

A restaurant app that lets diners pick a specific table on a live 2D floor plan, pre-order
food, and have the kitchen time preparation so the meal is ready when they arrive.

## Files

| File | Contents |
|---|---|
| `Lab1_Requirements_Table.docx` | 5 functional requirements (FR-001 to FR-005) and 2 non-functional requirements (NFR-001, NFR-002), each with ID, type, description, priority, acceptance criteria and rationale |
| `Lab1_UseCase_Diagram.pdf` | UML use-case diagram — 4 actors, 9 use cases, with «include» and «extend» relationships |
| `Lab1_UseCase_Flow.docx` | Use-case flow for UC-01 Reserve Table with Pre-Order — preconditions, postconditions, main success scenario and alternate flows |

## Actors

Diner, Restaurant Manager, Payment Gateway (external system), Kitchen Display System (external system).
